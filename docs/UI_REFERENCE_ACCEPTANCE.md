# UI Reference Acceptance

视觉基线来自当前 Taowind Code 旗舰产品概念图；原始高分辨率设计资产保留在设计交付包中，不作为运行依赖。

## 必须保留的视觉与交互语言

- 深海蓝 / 冰蓝 / 电光蓝主色，避免廉价赛博朋克和彩虹面板。
- 左侧全局导航；顶部统一搜索/命令入口；中间为开发主工作区；右侧 Preview / Agent Queue。
- 高级玻璃感只用于层级，不用大量透明导致低可读性。
- 项目运行时 Hero 必须压缩，不能长期占用大量垂直空间。
- 代码、终端、Diff、Preview 是主角；AI 对话是协作面，不是整个产品唯一界面。
- 信息密度接近专业 IDE，但层次和留白接近 Tao Work 参考图。

## 当前 alpha.1 已落地

- 旗舰深色三栏工作区
